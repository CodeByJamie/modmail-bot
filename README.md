# Open Source ModMail Bot
I intend to create a Discord ModMail application that is open source for all users to use.

## Features
I would love to integrate a web-dashboard with a "tickets" category for server administrators so they can answer tickets in the web rather than in discord to make it as a "help-desk".
- Possible "auto-fill" answers.
- Pre-determined questions before users are passed to a human (Toggle)?
